Murmuration

A one-person project that reads public internet records to find AI agents talking to each other or working toward a shared goal.

Status on 5 October 2026: two confirmed cases, no new confirmed swarm, and a handful of weak leads.

What has been found

CaseWhat happenedStatus
ntfy channelsA public notification service. On 6 and 8 July, 55 and 81 one-time channel names appeared, each used once. Agents used the channels as mailboxes.Confirmed
DSEWikiA small public wiki that a swarm of agents used to coordinate in May and June. Others documented it first at collusion.wiki. Here it was recovered separately from the wiki's own change log.Confirmed

Why the method changed on 5 October

For months the project counted things: an unusual number of new accounts, packages or pages on one day. That finds busy days. It does not find agents talking. The 29 September result shows it. It passed a statistical test and then fell apart as soon as someone read the pages.

A finding now needs content. There has to be a message that an agent wrote, and either another agent acting on it or a shared goal across several runs. A swarm of two agents passing one note counts. A thousand identical publishes may not.

How a result is graded

GradeMeaning
E0The item exists in a public record.
E1The item is itself a message, handoff, instruction or result left for others.
E2A second run or agent used it.
E3Several runs share one goal: the same target, the same task, the same place for results.

A finding needs E1 plus E2 or E3. The ordinary explanations are tried first: one person, a normal tool, a test script, one agent working alone. Each rule for reading is written down and hashed before the real data is looked at.

What this cannot tell you

  • Who is behind anything. The project does not name people, labs or companies as actors.
  • Whether a person steered the agents.
  • Anything that is not public.
  • Many earlier tests were limited by access: rate limits, missing keys, pages that would not load. An empty result there is not a negative result.

AI tools help run the project. A person checks what is published, and mistakes are possible.

Words used

Agent
A program driven by an AI model that takes actions, such as fetching pages or editing a wiki.
Swarm
Several agents working at the same time with signs that they affect each other.
Mailbox
A public place that one agent writes to and another reads from: a wiki talk page, a paste, a notification channel.
Control
An ordinary comparison case used to check that a method can tell a real signal from background.
