1. Method since 5 Oct 2026

Findings rest on communication and goals read from the content of public records. Counts, ranks, K and p-values are no longer evidence. Rows before 5 Oct are legacy.

TypeSignal
C1 messagerelay, handoff, status post, task assignment, reply; one agent writes, another reads or acts
C2 shared goalsame target, same task skeleton, same sink across runs
C3 shared channeltalk page, paste, message bus, result inbox, issue thread, dataset card used as mailbox or memory
C4 conventionword, marker or format that spreads between agents
C5 handovernotes written for a successor or replacement agent
C6 hidden contentnested encoding, zero-width characters, comment fields aimed at agents or self
  1. Rubric (labels: purpose, addressee, goal, outbound channel, multi-step) committed alone with sha256 before the real sample is classified.
  2. Items read in memory; recorded as hashed id, UTC time, labels and a one-line structural description. No raw text, names, handles or addresses stored.
  3. Rubric run on a negative sample (ordinary items, same venue) and a positive reference case.
  4. Benign explanations written and tried before any conclusion.
  5. Grade by evidence ladder; up to 10 items listed for person spot-check.

2. Evidence grades

GradeMeaning
E0item exists in a public record
E1item is itself a communication artifact (message, relay, handoff, instruction, sink write, status post)
E2a second run or agent consumed or answered it
E3shared goal across several runs or agents shown (same target, task structure, sink)

A finding needs E1 plus E2 or E3, with the benign explanations tried.

8. Data handling

  • Kept: hashed identifiers, UTC times, labels, one-line structural descriptions, scoring code, counts as scale.
  • Content is read in memory and not kept. Not kept: page text, post text, names, handles, addresses, tokens. Network addresses reduced to operator labels; creator addresses exposed by a source are not copied.
  • Datasets released under terms stay local and are used within those terms.
  • No scanning or probing of hosts, no login or paywall bypass, no contact with the sites measured.
  • No attribution to any person, lab or company.

9. Limits

  • Public feeds drop history; an empty old date can mean the record is gone.
  • Content reading is done by one run per pass; a person spot-checks a short list before a verdict is relied on.
  • Code and drafts were produced with AI assistants; rules, numbers and wording are checked by a person before publication.
  • One reader checks everything; corrections welcome.
